# Aleksreport — готовая публикация

Статическая сборка сайта фотографа Александра Кузнецова.

Адрес GitHub Pages: https://kuznetsovphotographer-prog.github.io/aleksreport/

Публикация: GitHub Pages → Deploy from a branch → main → / (root).
Сборка уже выполнена: Node.js на хостинге не требуется.
Базовый путь: /aleksreport/. Для собственного домена требуется пересборка с BASE_PATH=/ и соответствующим VITE_SITE_URL.

Исходный рабочий проект хранится отдельно; этот репозиторий содержит готовые HTML, CSS, JavaScript и медиафайлы.

Форма заявки: серверный CONTACT_ENDPOINT пока не подключён. Без него используется подготовка письма через почтовое приложение; доставка в CRM не настроена.
