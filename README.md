# Aleksreport — публикация для основного домена

Готовая статическая сборка сайта Александра Кузнецова для `https://aleksreport.ru/`. GitHub Pages публикует ветку `main` из корня репозитория; исходный рабочий проект хранится отдельно.

- `BASE_PATH=/`, `VITE_SITE_URL=https://aleksreport.ru`.
- Формы отправляют заявки напрямую в Yandex Cloud Function; персональные данные сохраняются в YDB. Служебные Telegram-уведомления для нового источника пока выключены.
- `CNAME` сохраняет основной домен `aleksreport.ru`.
- `robots.txt` запрещает обход семейных изображений. Абсолютной гарантии исключения изображений из поисковых систем этот запрет не даёт.

Свадебная, семейная и репортажная страницы включают тематические подборки и полные галереи: 163, 60 и 115 фотографий соответственно. Черновик отзыва компании отображается только в локальном просмотре.

Семейная страница сохраняет `noindex,follow,noimageindex` и исключена из sitemap; свадебная страница открыта индексации.

Сборка от 28.10.2026 проверена: 12 статических страниц, 21 маршрут и 649 ссылок на локальные ресурсы. Исходный проект, оригиналы фотографий и локальные отчёты хранятся отдельно от этого репозитория.
